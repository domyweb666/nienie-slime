# 標準清單（v2.24，2026-11-04）

規格來源：`.uiux/04-手感/手感診斷-暫定.md` 第二節 F1、F2、F3。

## 必須做到（你親手就能測）

- [ ] 我打開 app，史萊姆應該比以前明顯大，寬約 4 公分，整隻都在畫面裡。
- [ ] 我用一根手指按在它正中間，應該還看得到大半個身體和兩顆眼睛（眼睛會滑開，不被手指蓋住）。
- [ ] 我點它一下，應該一眼看得出它縮一下，接著朝我的手指傾過來。
- [ ] 我的手指放在它身上不動，應該看得出它左右蹭我的手指。
- [ ] 我的手指放在它身體左邊或右邊，應該看得出整張臉往我的手指那邊滑。
- [ ] 我用平常的速度揉圈圈，2 秒內眼睛應該彎成 ∩、聽到「嗯～」、iPhone 開始呼嚕。
- [ ] 我來回揉（一秒 2、3 趟，幅度約 1 公分），它應該舒服，不會逃走。
- [ ] 我很快地小幅度撥它，應該看到它扭來扭去、咯咯笑；撥久了先抗議、再掙脫，大約 6 秒。
- [ ] 我從身體中間直直往外拉，外緣應該很快跟著被拉出去，不會只有裡面動。
- [ ] 我揉的時候，外框不應該冒出尖尖的折角。
- [ ] 我往外拉一小段（約 1 公分），畫面不應該縮小。

## 絕對不准做

- 不准動到：黏土的留形（放手 2 秒還留約八成、15 秒退一半）、拖著走的拉力、兩指捏與兩指拉、黏液、睡著、照節奏回你、四隻史萊姆的個性。
- 不准擅自加：新的反應種類、新畫面、F4 以後的東西（慣性、觸覺重做、摸、肌肉）。
- 不准改硬規則：線性形狀匹配不開、邊界繩子、群內互不穿透、Q0 零均值。
- 休息時的呼吸與蠕動比例不准加大（多米 v2.11：自身形變不要太大）。

## 每條的意圖

- 放大：手指 1.6 到 2 公分，身體 3 公分時手一放就蓋掉一大塊。
- 眼睛滑開與整張臉滑過去：v2.23 判斷缺的是注視，5 點的位移讀不成在看你，手指又常蓋住眼睛。
- 縮、傾、蹭放大：這些動作在手機上不到 1 毫米到 2 毫米，做了也不容易看到。
- 揉的門檻：一般手速的揉現在完全沒反應，來回揉還會逃走，最常做的動作不該被它忽略。
- 補抓只在往外拉時：揉的時候不能把外框釘在手指上。
- 不縮畫面：身體變大之後鏡頭不能一拉就退，手指底下的東西要穩。

# 標準清單（v2.25，2026-11-04）

規格來源：`.uiux/04-手感/手感診斷-暫定.md` 第二節 F4、F5。

## 必須做到（你親手就能測）

- [ ] 我拉它一段放手，看得出它在回彈（第一下約 0.15 秒），晃兩三下才停，不會一閃就回去。
- [ ] 我拉黏土放手，形狀照樣留著（2 秒還留約八成），回彈只是表面晃一下。
- [ ] 我快速把它拖走再突然停，遠端慢一拍才跟上，到了再晃一下。
- [ ] 我放手或甩它，手機先「啵」一下，接著跟晃動同節奏再來幾下小的；輕輕放手只有一下。
- [ ] 我揉的時候手上一粒一粒的，手一停就停，不會一直嗡嗡。
- [ ] 我拉得越長，一粒一粒越密、越脆。
- [ ] 我按下去，第一下之後幾下越來越輕，像在往下陷；按完就安靜。
- [ ] 呼嚕是一陣一陣的低頻震動。
- [ ] 面板有「觸覺階梯」，點一下震一個強度，我能說出最小感覺得到哪一格。

## 絕對不准做

- 不准手停了還在嗡嗡。按住時每次吸氣那一下（約 3 秒一次）、按著 0.35 秒後那一下輕頂是它自己的動作（v2.19、v2.22 就有），不算；面板「A4 碰著也在呼吸」「E2 動作都有它的回應」可以關。
- 不准一秒超過 20 下顆粒（手麻）。
- 不准動到：黏土的留形、v2.24 的跟手（手指跟被抓那塊的距離）、揉的呼嚕時間、拉力。
- 不准放手那一幀形狀跳一下。
- 不准擅自加：F6 以後的東西（摸、手指旁邊的畫面、肌肉）。

## 每條的意圖

- 回彈放慢、拖動有慣性：33 毫秒彈完、每秒晃 7 下，讀起來像很小的橡皮。
- 留形不動：多米 v2.14 嫌回彈太快，那是形狀退太快，表面的晃跟它不衝突。
- 顆粒與按下去的漸弱：揉時連續觸覺約 0.05，手上幾乎沒東西；手機沒有力道感測，用時間和接觸面積代替。
- 不要一直嗡嗡：實物握著不動時手指感覺不到什麼，感覺到的是正在變。
- 觸覺階梯：查不到 iPhone 多低感覺不到，只能真機回答。

# 標準清單（v2.26，2026-11-04）

規格來源：`.uiux/04-手感/手感診斷-暫定.md` 第二節 F6、F7。

## 必須做到（你親手就能測）

- [ ] 我的手指快速從身體左半劃到右邊外面，手指應該滑過去，身體只被帶一小段（約 4 毫米）再回來，不會被拖走。
- [ ] 我連續摸它兩三下，2 秒內它應該舒服（眼睛 ∩、呼嚕），不會逃走。
- [ ] 我先按一下再拉，照舊抓得住、拉得長。
- [ ] 我從邊緣快速往外扯、從正中間往外拉，照舊抓得住。
- [ ] 我摸到一半手指停在它身上，那塊應該被抓住，接著拉得動。
- [ ] 我兩指快速往兩邊拉，照舊拉長。
- [ ] 我按著不動，手指外面看得到一圈陰影和亮邊。
- [ ] 我揉或摸的時候，手指走過的地方留一條淺淺的痕跡，半秒內淡掉。
- [ ] 我把它拉長，白色亮光跟著被拉長。
- [ ] 我摸黏土，形狀不會被留下來。

## 絕對不准做

- 不准動到：拉力、黏土的留形、揉的呼嚕時間、放手的晃、顆粒、兩指捏與兩指拉。

- 不准擅自加：v2.27 的東西（肌肉、自己收回形狀、手指下的呼吸）。

## 每條的意圖

- 摸跟抓分開：手指劃過身體時整團被帶走，對一隻動物做的第一件事變成把牠拖走。
- 寧可把摸判成抓：抓是這個 app 的主要動作，判錯成摸會覺得抓不住；判錯成抓只是回到現在的樣子。
- 手指旁邊看得到：凹痕半徑 17 到 26 點，手指接觸面半徑約 30 點，按著時整個凹痕都在手指底下。

- [ ] 我把一條觸手拉過身體拖到另一邊，放手後不會纏住，也不會一直抖。
- [ ] 我抓著觸手不動，它不抖。

- [ ] 沒人碰、心情平穩時，四隻都是自己原本的顏色。

## 絕對不准做

- 不准改硬規則：線性形狀匹配不開、邊界繩子、群內互不穿透、Q0 零均值。
