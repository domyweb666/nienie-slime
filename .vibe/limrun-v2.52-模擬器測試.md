# limrun 模擬器測試：v2.52 手機版（給多米本機的 Claude Code 跑）

> 2026-11-22 雲端 Agent 寫的。**它沒有 lim 的登入，沒有實際跑過這份**；指令以 `lim --help`、`lim ios --help`、`lim xcode --help` 為準，不要照字面硬跑。
> 分支 `feel-3x-panel-v1`（PR #1）。CI 已經在 Mac 上編過（BUILD SUCCEEDED）。

## 為什麼要跑、跑了能知道什麼

CI 只證明編得過。模擬器能再驗一層：**打得開、不閃退、調節台畫面排得對、按鈕有作用、亂捏測試跑得動**。
量不到的：延遲、手感、震動、120 Hz、真機的每格毫秒。那些還是要多米拿真機測（`.vibe/標準清單.md` v2.52 一節）。

## 規矩（照 repo 之前的 limrun 紀錄）

- `export LIM_DAEMON=false`；指令一律帶 `--id … --no-create`。
- 開機帶 `--label project=nienie-slime --inactivity-timeout 10m --hard-timeout 40m`。
- 按分鐘計費：整份 20 分鐘內做完；測完 `delete`，再 `list` 確認沒有留著的實例。不是自己開的實例不要動。
- 以前只用它測過網頁版（模擬器的 Safari）。原生 app 要用它的遠端 Xcode 編成模擬器版再裝上去（`lim xcode …`；專案檔要先用 `ios/project.yml` 跑 xcodegen 產生）。bundle id：`org.domyweb.nienieslime`。
