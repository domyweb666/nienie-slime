## B7 量的是哪一段

時基：`UITouch.timestamp`、`CADisplayLink`、`CACurrentMediaTime()` 都是開機後秒數（睡眠時停），同一把尺。
量到：手指時間戳 → 程式收到、叫聲音前後、叫震動前後、下一格開始算、交出去、`targetTimestamp`。
沒量到：玻璃到時間戳、合成和面板、喇叭、馬達。`targetTimestamp` 是系統排的時間，不是真的亮起來。
記在 64 格固定環狀緩衝，調節台打開才記。複製時才配置記憶體。

## 給別人的待辦

1. **JellySkin（S1 的檔）**：要真的 present 時間，加 `var onPresented: ((CFTimeInterval) -> Void)?`，在 `render` 的 `cmd.commit()` 前加
   `if let f = onPresented { drawable.addPresentedHandler { d in let t = d.presentedTime; DispatchQueue.main.async { f(t) } } }`。我沒改。
2. 量皮不是讀 GPU 貼圖（`maskG`、`h2` 是 private）。現在是拿同一份三角形和線在 CPU 重畫、同樣的模糊和 0.46 再數；GPU 自己畫錯的看不到。要真的讀回，JellySkin 加 blit。
3. SlimeRig 不用多露屬性。

## 量皮的成本

主執行緒：量的那 5 秒每格抄幾十 KB；背景：一次一張，沒數完就跳過。毫秒沒量過，面板上會顯示實際數字。塊 0.004R²、洞 0.002R²、突跳 0.12R，跟 `probe.js` 一樣。「身體自己走多遠」用外框點，網頁用全部粒子。
