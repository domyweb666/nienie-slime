## 2. 跟補丁不一樣的地方（都照網頁正式版）

1. **停住的計時**。補丁的 `F1S` 只在 `cr` 開著、而且那一格真的走到記形那條路時才加（外框交叉的格、只抓觸手、揉回原形時不加），放手也不歸零。網頁 v2.61 改成每一格都算，沒有手指抓就歸零，Swift 跟網頁一樣。
   - 差別只在「交叉的那幾格也算停住」，會早幾格定住。
   - **`gv` 用的就是這個計時。補量的 b 組（只開 `cg gv bl`、沒開 `cr`）裡 `F1S` 一直是 0，`gv` 其實沒作用過；`gv` 單開沒有任何一個量過的數字。** c 組（`cr` 開著）有作用。
2. Swift 的計時多一層：`pullHold`、`pullSoft` 都關就是 0（網頁關著也在數，但沒人讀）。手沒放就切開關時，Swift 從 0 數、網頁可能已經數滿。合約寫手放開才切，碰不到。

## 4. 三顆都是 0 時

- 沒有新的亂數（沒有新增 `Double.random`）。
- 每個判斷都先看開關：`moodRelease` 的 `&&`、`shortEnough` 和 `grows` 的 `||`、`relCap`、回正、`heldBack`、`kc`、`dragTarget`，都是短路，後面的 `memLen`、`pullMoving` 不會算。
- 兩個地方式子變了但數字一樣：Verlet 原迴圈搬進 `else`（內容沒動）；`dragTarget` 回傳多 `0 +`（20 萬組輸入逐位元比過差 0）。
- `pullStillT` 一直是 0；`r0x r0y` 抓下去照記，關著沒人讀。
- 沒有在手機上量狀態差。
