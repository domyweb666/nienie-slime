# W2 移植說明（網頁 `index.html` 的 D1、D2、C3 → Swift `SlimeRig.swift`）

開關：`rough`、`tapSoft`、`petSlow`，大於等於 0.5 算開。三顆都 0 要跟 v2.61 的 W1 逐點相同（網頁驗過：芋圓、薄荷各 2 種子，粒子座標、記形、情緒、畫面像素、出聲全部一樣）。
R＝一個半徑。速度都用手在螢幕上的速度：`hypot(vxS, vyS) × CAM.z ÷ R`（vxS 是 30 毫秒平滑那組，不是單幀差分）。

## D1 `rough`：只有快扯算欺負
常數 `ROUGH`：v 6（每秒 6R）、st 0.8（R）。

每根手指多兩個狀態，落下時都是 0／false；`strokeGrab`（摸轉抓）也要歸零：
- `vMax`：這一抓最大手速，不衰減。
- `yank`：這一抓扯過沒有，一旦 true 就到放手。

每幀（抓著，算完 `stretch` 之後）：手速 > `vMax` 就更新；`yank` 還是 false，而且手速 ≥ 6、`stretch` > 0.8、（`ex,ey`）跟（`vxS,vyS`）內積 > 0（往外），就設 true。

用在哪：
| 地方 | 開著時 |
|---|---|
| `moodStep` 的 `strainT` | 累積條件多一個 `yank`。其他不動：拉開 1.5R、撐 0.5 秒開始、1.5 秒滿。沒有 `yank` 就每秒退 1，所以慢拉 `strain` 一直是 0，連帶沒有抗議聲、放手不逃 |
| 往回拔（`tugX/Y`） | 另外記 `g.tugT`、`MOOD.tugS`，算法跟原本的 `strainT`、`strain` 一模一樣，只是不看 `yank`；放手照 0.2 秒退；`emo` 關時歸零。`tg = (rough ? tugS : strain) × R × .35`。不這樣分開的話，芋圓往上慢拉 4R 停住的高度從 5.5R 掉到 4.8R（拉長的形狀會變）。分開後 3R 一樣（4.5R），4R 還差 4%（5.25 對 5.48，`c` 不再被扣、姿勢不同） |
| `impRelease` | `hard = vMax ≥ 6`。`strainMax > .15` 那支：戒不加、熟不扣。`fling` 那支關掉（甩不加戒）。最後那支：`yank` 時戒不乘 0.8；`hard` 時沒有 +0.12 |
| `impStep` 慢慢拖那支（+0.02） | `vMax ≥ 6` 時不給 |
| `moodColorStep` 的紅 | 只看 `yank` 的手指（拉伸量、手速那兩項）；`strain`、`ESC` 照舊 |
| `> <`（`EYE.sqU`） | 多一個 `yank` 條件；原本是 5R／秒、拉開 0.8R |

不動：`moodRelease` 的逃、C3 脫手（`impC3`，那是 D3）、`lifeRelease` 的甩一甩和喘。

## D2 `tapSoft`：慢點不算攻擊
「點」照舊：按下到放手 < 0.25 秒、`stretch` < 0.3。一秒內的次數＝`MOOD.taps`（清掉一秒前的、加上這一下）。
- `moodRelease`：次數 < 3 時，不加 `scare` 0.45、不扣 `c` 0.1、不設 `cowerUntil`；`a` 照舊 +0.3。次數 ≥ 3 照舊（嚇、縮著、逃）。
- `impRelease`：次數 < 3 時戒 +0（原本 +0.04）；≥ 3 照舊 +0.2、熟 −0.1。
- 手機沒有心情和記地方，搬大腦時不用另外改：兩個都是跟著 `scare`、`IMP.w` 扣的，沒漲就不扣。

縮一路變小（原本 `FLN.H` 只有 7 秒，加上「被碰前在做什麼」的 0.8／1／1.2 倍，會忽大忽小）。常數 `TAPK`：k 0.93、T 90 秒、lo 0.3。`FLN` 多三個狀態：
- `tc` 上限，初始 1（等於沒限制）。每幀 `tc = min(1, tc × exp(dt/90))`；`tapSoft` 關就固定 1。
- `tpAt` 手指碰出來的那一縮排在幾秒（`down` 設 `FLN.at` 時一起存）。縮的時候 `FLN.at == tpAt` 才算碰出來的，嚇醒、東西倒、快手指那幾種不受限。
- `tcq` 這一下已經判定是輕點，但縮還沒到。
- 縮的那一幀（碰出來的）：`a = min(a, tc)`；`tcq` 是 true 就記：`tc = max(0.3 × flinchAmp, min(tc, a × 0.93))`。縮完 `tcq = false`。
- `moodRelease` 輕點時：縮還沒到就 `tcq = true`；已經縮過（`FLN.t0 > f.tDown`，要大於，不能等於）就直接用 `FLN.amp` 記。
- 滿三下：`tc = 1`、`tcq = false`。
- 歸零：`setup()` 重設 `FLN` 那裡。

## C3 `petSlow`：慢慢摸累積
抓和摸的判斷（`strokeJudge`、`strokeV`）不動。只影響 `PURR` 和熟，不動舒服 `c`、戒、身體、放手的小跳。
常數 `PETK`：cm 1.8（一個 R 算 1.8 公分）、lo0 0.5、lo 1、hi 10、hi0 14（公分／秒）、rate 2.5、cap 0.8、rin 1.1、rout 1.25、c0 0.35（R）、gap 0.6 秒、out 0.6、max 3。
狀態：全域 `PET {g, last, on, said}`；每根手指 `pt {cx, cy, sx, sy, px, py, ml, run, sum, x}`，第一次數到那一幀建（cx、cy＝當時的身體中心，之後不跟著身體走，所以 A4 把整隻帶走也不影響）。摸轉抓、抓轉摸是同一個 `pt`。

`petStep(dt)` 在 `moodStep` 裡、找 `g` 之前跑：
1. `on = false`；開關關著就把 `PET` 歸零返回。
2. 手指（抓或摸著身體）恰好一根才數；畫面上有第二根手指（不管碰什麼）就不數、也不呼嚕。
3. 一趟：從（sx,sy）出發；記離出發點最遠的點（px,py,ml）。從最遠點退回超過 0.15R、方向相反，就是折返：出發點換成那個最遠點、`run = 0`。
4. `away`（這一趟不算）：出發點離中心 < 0.35R，或出發點的向外方向跟走的方向夾角餘弦 > 0.5。跟 `strokeJudge` 同一條。從中心慢慢往上拉的誤判就是這條收掉的。
5. 抓著而且離 cx,cy 超過 1.25R：`x = true`（這一抓後面都不算），把這一抓加過的 `sum` 全退掉。
6. `pull = x`，或 `away` 而且走了 0.3R 以上，或 `yank`。
7. 快過 14 公分：`g` 每秒退 3。否則不是 `pull`、不是 `away`、離 cx,cy < 1.1R、快過 0.5 公分、沒在搔癢、`strain < .05`、沒在逃：`g += rate × dt × min(1, (v−0.5)/0.5, (14−v)/4)`，這一趟最多加 0.8（`run`）、`g` 最多 3；`last = t`（加滿 0.8 之後也要更新）。
8. 超過 0.6 秒沒摸（或 `last` 在未來）：`g` 每秒退 0.6。
9. `on = g > 1 而且不是 pull、手指不到兩根、t − last 在 0 到 0.6 秒、沒在搔癢`。`g < .5` 時 `said = false`。

用在哪：
- 呼嚕目標：原本的 `pt` 跟 `on ? min(1, (g−1)/.5) : 0` 取大。
- 熟：`on`、`t − last < .05`，而且這一幀沒走輕揉那支、也沒走摸那支（不重複算）：`+= (.04 + .04×PURR) × dt × (e3 ? 3 : 1) × trRate`。戒不動。
- 「嗯～」：`on` 而且 `said` 已經 true 就不再哼；哼過設 true。抓著那支、摸那支都要看（不然一下一下摸，每一下都哼）。
- 歸零：`setup()` 跟 `STK` 同一處。

## 放著沒動、要知道的
- 快扯之後很快放手（撐不到約 0.65 秒）不會逃，跟 v2.60 一樣；`> <` 和紅會出來。
- 手指從身體外面慢慢推進來（網頁叫 push）不算摸，跟 v2.60 一樣。
