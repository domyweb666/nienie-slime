### 環境與設定（不變的事實）

- 多米沒有 Mac。編譯走 GitHub Actions，裝機走 TestFlight；build 號＝run number
- `swiftui-port` 有 Swift＋web＋docs；`main` 只放 web＋docs（Pages 自動發布）。推 main 用暫存 worktree cherry-pick，`ios/` 保留 main 自己的，`prototype/`、`.uiux/`、`CLAUDE.md`、`.vibe/` 直接取 swiftui-port 的版本
- 發 TestFlight：先等 push 觸發的編譯過，再 `gh workflow run ios.yml --repo domyweb666/nienie-slime --ref swiftui-port -f testflight=true`；上傳完成前不推同分支
- selftest 在本機跑：`.claude/launch.json`（在 `E:\捏捏史萊姆\`）的 web-proto（python http.server 8765），手機尺寸 375×812，`fetch('selftest.js')` 後 eval，連跑 3 次；瀏覽器窗格隱藏時一次 javascript_tool 最多等 45 秒，要讓它背景跑、再分次讀 `window.__runs`
- JS 原型很多一行多句：註解一律加在行尾最後（這次兩次把後半行註解掉，身體變 NaN、啵消失）
