# 黃金行為（每次改動後都要重玩一遍）

機器這邊跑 `prototype/web/selftest.js`（連跑 3 輪以上）；下面是人親手玩的版本。

1. 我拉黏土的邊往外 2 公分放手 → 它留著被拉長的形狀，慢慢才退回去。
2. 我往右下拉它 → 整隻跟著往右下靠。
3. 我用平常的速度揉它 → 2 秒內舒服（眼睛 ∩、呼嚕），不會逃走。
4. 我按在正中間 → 看得到大半個身體，手指旁邊有一圈凹痕。
5. 我兩指往兩邊拉 → 拉得很長，不交叉、不抽搐。
6. 我拉它一段放手 → 看得出在回彈，晃兩三下才停；黏土的形狀照樣留著。
7. 我揉它 → 手上一粒一粒的，手一停就停。
8. 我快速從身體一邊劃到另一邊 → 手指滑過去，它只被帶一小段再回來。
9. 我按著不動 → 手指上方看得到一圈陰影。
10. 我從身體側邊快速往下拖 → 抓得住，身體跟著走。
11. （面板「固定觸手數」8 才有）我抓一條觸手尖端往外拉 → 跟著我走，抓著不動不抖。
12. （面板「固定觸手數」8 才有）我把觸手往身體裡推 → 從手指滑開，不纏住。
13. 我揉它 → 慢慢偏粉橘，放開一陣子回原色。
14. 我亂拉亂甩它 → 兩顆眼睛一直在身體裡。
15. 我抓著它繞圈、拖過自己的身體再放手 → 1 秒後外框沒有結。
16. 我猛扯、用力甩 → 不會掉黏液。
17. 我搖手機三下（網頁：面板「搖：假裝搖三下」）→ 牠在碗裡彈一下、眼睛 ∩，整團變霧、亮粉揚起來。再搖不會更霧。
18. 我放著不碰 → 牠閉眼慢慢呼吸，亮粉慢慢沉，約 30 秒清透、發光、叮一聲、睜開眼，底部堆一座小堆。
19. 沉到一半我捏牠 → 又濁回去一點，清的那一下延後。
