# 黃金行為（每次改動後都要重玩一遍）

機器這邊跑 `prototype/web/selftest.js`（連跑 3 輪以上）；下面是人親手玩的版本。

1. 我拉黏土的邊往外 2 公分放手 → 它留著被拉長的形狀，慢慢才退回去。
2. 我往右下拉它 → 整隻跟著往右下靠。
3. 我用平常的速度揉它 → 2 秒內舒服（眼睛 ∩、呼嚕），不會逃走。
4. 我按在正中間 → 看得到大半個身體和兩顆眼睛。
5. 我兩指往兩邊拉 → 拉得很長，不交叉、不抽搐。
6. 我拉它一段放手 → 看得出在回彈，晃兩三下才停；黏土的形狀照樣留著。
7. 我揉它 → 手上一粒一粒的，手一停就停。
8. 我快速從身體一邊劃到另一邊 → 手指滑過去，它只被帶一小段再回來。
9. 我按著不動 → 手指上方看得到一圈陰影。
10. 我從身體側邊快速往下拖 → 抓得住，身體跟著走。
