# 捏捏史萊姆

一款 iOS 原生的 2D 卡通史萊姆 App：打開就能捏，拉、壓、推，揉久了會留形。牠住在窗台上的碗裡，你走路牠會帶小東西回來，搖手機牠會變霧再慢慢清。

## 目前狀態（2026-11-07）

- `prototype/web/index.html`：網頁原型 **v2.31**，所有設計都先在這裡做、在 iPhone Safari 上捏過才搬手機。形狀匹配軟體（Shape Matching）＋黏土塑性，約 360 顆粒子，不爆、不打結。現在有：窗台、正中間的碗、白天夜晚背景、果凍皮（WebGL2）、兩顆眼睛、活物感與印象、走路帶東西回來（面板假裝步數）、搖晃沉澱（含網頁才有的「散出來吃回來」）。長按標題開調整面板。線上版（GitHub Pages）：<https://domyweb666.github.io/nienie-slime/prototype/web/index.html>。網頁沒有觸覺、延遲跟原生不同，只能看形狀與手勢邏輯，不能當手感驗收。改演算法要在瀏覽器 console 跑 `prototype/web/selftest.js`，連跑 3 輪全 PASS 才推。
- `ios/`（`swiftui-port` 分支）：SwiftUI 移植版，2026-11-07 晚上分七批追到網頁 v2.31（刪黏液、防打結、窗台與碗、爬出爬回碗、走路含 CMPedometer 真步數、CoreMotion 搖晃沉澱、Metal 果凍皮）。build 117 已發 TestFlight，七批只過了 GitHub Actions 的編譯，還沒有一批在真機跑過。編譯與上傳的步驟在 `ios/README.md`。
- `.uiux/`：設計檔。`01-核心動作卡-暫定.md`（還沒過閘門 1，三個真人測試未做）、`04-手感/` 的參數表、各版提案、移植批次。
- `.vibe/`：工作文件。`HANDOFF.md` 是給下一個會話的交接，`標準清單.md` 每版的驗收項，`代決清單.md` 是 Agent 替多米決定的事，`黃金行為.md` 每次改完要重玩的 20 條。
- `prototype/web/archive/`：試過但手感未達標的版本（三角網子、MPM 顆粒、放射狀 rig），僅供參考。
