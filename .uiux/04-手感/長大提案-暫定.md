# 長大提案（暫定）：一開始小，捏過的天數越多越大

> 2026-11-08，回應多米：「大小一開始比較小，然後隨著互動捏的動作天數他會越來越大呢？只是大小的最大值就設定呈現在這樣。」
> 狀態：提案，等多米點頭才動工。最大值＝現在網頁 v2.33 的大小（面板「身體大小」0.30，iPhone 寬 393 點時身體寬約 4 公分）。

## 我覺得好不好

好，我贊成。它剛好補上定位裡最弱的一塊：一句話任務寫「你捏牠牠會記得你」，可是「熟」只表現在行為上，第一天跟第七天放在一起，外人看不太出差別。身體大小一眼就看得出來，窗框又是固定的，牠比上禮拜大了一圈，不用任何數字你也知道。

這也是 Finch 最會的那招：你做的事變成寵物看得見的變化。

要先講的衝突：定位文件「不是給誰的」寫了「想養成、想看數值漲的人。沒有等級」。長大其實就是一條看不見數字的等級。我覺得可以接受，條件是畫面上永遠不出現數字、進度條、「升級了」這類字。定位文件那一行要跟著改成「有長大，但沒有數字」。

## 規則

| 項目 | 建議 | 為什麼 |
|---|---|---|
| 算什麼 | 「有捏過的天數」，一天只算一次。當天手指碰牠累計 20 秒以上就算 | 算天數不算捏的總量，一天狂捏一小時跟捏 20 秒一樣，不會變成要刷的功課 |
| 一天最多長多少 | 一格。隔天打開才看得到 | 長大要有「隔了一晚」的感覺，像真的動物 |
| 會不會變小 | 永遠不會。幾天沒來就停在原本大小 | 不懲罰是底線 |
| 走路算不算 | 不算，只算捏 | 你說的是捏的天數；走路已經有「帶東西回來」和「興奮」兩個回報 |
| 長到最大之後 | 停在 0.30，之後靠熟、走路帶東西撐 | 最大值你定的 |

## 起點和曲線

起點建議 0.22。這是 v2.10 到 v2.23 用了快兩週的大小（寬約 3 公分），你捏過很多輪，手感是熟的。

曲線用前快後慢：頭幾天長得最明顯，後面慢慢逼近最大值。公式是 大小 ＝ 0.22 ＋ 0.08 ×（1 − 0.8^捏過的天數）。

| 捏過的天數 | 身體大小 | 寬（約） | 跟前一天比 |
|---|---|---|---|
| 0（剛裝） | 0.22 | 3.0 公分 | |
| 1 | 0.236 | 3.2 公分 | 大一點，看得出來 |
| 3 | 0.259 | 3.5 公分 | |
| 7 | 0.282 | 3.8 公分 | |
| 10 | 0.291 | 3.9 公分 | |
| 14 | 0.296 | 4.0 公分 | 幾乎到頂 |
| 20 以上 | 0.30 | 4.0 公分 | 最大 |

捏三個禮拜左右長滿。數字都是我取的：想讓牠長慢一點，把 0.8 改大（0.85 大概一個月長滿）；想要起點更小，見下面風險第一條。

## 長大那一刻怎麼演

隔天第一次打開，牠先用昨天的大小出場（從窗外回家，或冷啟動的開場），到家看你一眼，然後伸個懶腰：整團往上拉長一下、縮回來，這時候變成新的大小，「嗯～」一聲。iPhone 輕震一下。不跳字、不放煙火。

沒長大的那天（前一天沒捏），開場照舊，不伸懶腰。

## 風險

1. **小身體在物理上比較不穩。** `手感診斷-暫定.md` 第 97 行量過：黏土在 0.22 的身體上暴力玩法有 45 幀交叉，放大到 0.30 才是 0 幀。v2.24 把身體放大，一部分就是為了這個。所以起點 0.22 要先在 selftest 三種材質暴力玩法量過，還有交叉就把起點拉到 0.24 或 0.25。這一條沒量過之前，起點不能再往下壓。
2. **手指會擋住更多。** 手指約 1.6 到 2 公分，3 公分寬的身體，按下去眼睛常被手指蓋住。第一天的人看不到牠的眼睛反應，會覺得牠比較沒反應。可以接受，因為第一天本來就還不熟。
3. **身體大小現在改了要重建。** 面板「身體大小」寫著「會重置」，粒子是照大小建的。伸懶腰那一下要嘛在動畫中途重建（藏在拉長那一幀），要嘛畫面先放大、物理之後才換。哪個做得到，動工時先試，試不出來就退回「開場前就換好，靠窗框對照看出來」。
4. **熟跨天還沒做。** 長大需要一個存起來的「捏過幾天」，跟熟跨天用同一個存檔位置，兩片一起做最省。

| 1 | 網頁：selftest 在 0.22、0.24 跑三種材質暴力玩法，量交叉幀數，決定起點 | 看數字就好 |
| 2 | 網頁：存「捏過的天數」（localStorage）、算大小、面板「假裝第幾天」滑桿 | 面板拉 0、3、7、20 天看大小 |
| 3 | 網頁：隔天第一次打開伸懶腰長大 | 面板「假裝明天」按一下看伸懶腰 |
| 4 | Swift | 等 build 117 過了，跟興奮、熟跨天、一隻為主一起搬 |

## 要你決定

1. 做不做。
2. 起點 0.22（建議，量過交叉再定），還是你想要更小。
3. 多久長滿：三個禮拜（建議）還是一個月。
4. 算「捏過的天數」，還是你其實想算捏的總量。
