# 手感研究與基準（暫定）｜捏捏史萊姆

> 2026-11-06，回應多米：「有沒有什麼研究紀錄，最好的手感應該要是怎樣？與其那麼多版，不如花時間研究最好的手感，其他換皮就好。」
> 查證方式：這次用網路查，表格最右欄寫我讀到多少（全文、摘要或片段）。延遲的數字來自《iOS 原生 App 的 UI／UX 準則》2-4，查證日期 2026-10。

## 先講答案

有研究，但沒有人研究過「虛擬史萊姆最好的手感」。我查到的研究能決定先做什麼、往哪個方向調，定不了數字。數字只能靠真機和沒摸過的人，書上也寫「參數沒有標準答案」（3-4 失效邊界 3）。

你的做法我同意。手感定成一份基準，皮、背景、擺飾、角色都不准碰它。二十幾版的問題在於從來沒有基準可以比，所以每版都只能憑感覺往上加。第二節是我建議的基準，第三節是怎麼收掉那麼多版，第四節是只有你做得到的三件事。

## 三、怎麼收掉那麼多版

分成三層，以後每個改動先問它在哪一層。

**手感層（基準管）**：身體物理、手指怎麼抓、拖、摸、放，聲音和觸覺的對應。這一層只准為了基準表上的數字改，一次改一個，盲測過才留。版本號不再往上加，改用「基準 v1 第幾輪」。

**皮層（隨便換）**：顏色、果凍皮、眼睛長相、背景、擺飾的樣子。換皮不能讓任何粒子多動一點，這條 selftest 已經在測（T43）。A、B 皮就是這層，你說等最後再選，完全不影響手感。

**個性層（幾個數字）**：四隻的差別只留在材質三組參數、個性、外形種子。環境互動的新玩法也放這層，規則是不准改手感層的參數，只能在外面加碰撞和行為。

另外有兩件事我建議一起做：舊版對照開關（面板和 selftest 裡的 v2.19 對照、v2.21 對照……）在基準 v1 定案後整批刪掉，那些開關讓每個新功能都要改三個地方；還有 v2.19 到 v2.23 那批反應（搔癢、討摸、打招呼）先凍住不再加，等三分鐘段的數字回來再決定去留。

## 四、只有多米做得到的三件

這三件一直欠著，研究查再多也換不到。

1. **買一個實物擺旁邊。** NeeDoh 或一盒史萊姆，一兩百塊。捏五分鐘，記下用幾根手指、最常做什麼動作、什麼時候放下。核心動作卡第一天就寫了「手機版要贏的是實物」，到現在還沒買。
2. **量延遲一次。** 打開面板「延遲測試」，手機慢動作拍手指和閃白，數格。十分鐘。這是基準表第 1 條，也是閘門 3 第 1 條。
3. **找一個沒摸過的人。** 只說「你可以玩玩看」就走開，記 10 秒和 3 分鐘兩段：捏多久才放下、有沒有笑、放下後有沒有又拿起來。不問意見。37 輪紀錄裡新的手是 0 輪。

## 五、這次已經照這個方向改的

拉扯時打結、眼睛跑出身體是物理問題，所以這次直接修在手感層。

| 窗台上，4 隻 × 7 種亂拉，共 9840 幀 | v2.28 | 這版 |
|---|---|---|
| 外框有交叉的幀 | 1141 | 275 |
| 一幀最多幾處交叉 | 53 | 11 |
| 放手 1 秒後還交叉的幀 | 62 | 0 |
| 記住的形狀裡翻面的三角形（共 962 個） | 最多 139 | 0 |
| 拉的當下翻面的三角形 | 最多 732 | 最多 584（放手 4 秒後只剩 0 到 4 個） |
| 眼睛跑出外框的幀 | 347 | 0 |
| 眼睛離外框最遠（負的是出界） | −66.7 點 | +5.8 點 |

代價：黏土的留形少了約 5%（拉 1.5R 放手 2 秒，0.79R 變 0.75R），跟手沒變（39 變 39.5 點）。拉的當下內部還是會翻，只是記不進形狀裡，放手幾秒就解開。

要自己比差別：長按左上「捏捏」開面板，把「防打結」設 0、「抓著時回正的上限」設 0.2，就是舊的。

修法：身體切成三角網，每個三角形不准翻面，記住的形狀也一樣；抓著時身體轉得動，被拉過去的那條不用纏在身上；整團被拖的速度有上限，手指附近那圈才不會被一下剪開；手指是實心的，拖過身體會把肉推開；畫面左右上緣是軟的。眼睛夾在外框裡，兩邊被拉開時眼距有上限。

這些都是程式自測，抓得到壞掉，抓不到好不好捏。好不好捏要你捏過才算。
