# 吹氣提案（暫定，不做）

> **多米 11-07 定：吹氣不做。** 這份留著當紀錄，裡面的麥克風測法、研究能講到哪，之後有別的機制要用麥克風再翻。
> 2026-11-06。方向來自多米貼的討論：跟現實互動的機制選吹氣。這份是把它改到做得出來的版本，標「建議」的是 Agent 加的，等多米定。

## 一句話

對著手機吐一口氣，果凍起波紋。吐得越慢越長，波紋從下往上推過整團，牠越安定、越亮。

## 為什麼是吹氣

多米定的三題篩選，吹氣都過：

| 題目 | 吹氣 |
|---|---|
| 現實那個動作本身就紓壓嗎？ | 長長吐氣本身就是呼吸練習，牠只負責回饋 |
| 跟果凍的物理對得上嗎？ | 吹氣起波紋，一看就懂，不用換算成點數 |
| 壓力最大的時候做得到嗎？不做會有損失嗎？ | 不用想、不用打字；不做沒有任何損失 |

另外兩個理由：跟捏一樣是用身體跟牠互動；「對牠吹氣，牠起漣漪」拍成短影音三秒看得懂。代價是少了長期收藏感。好事彈珠、煩惱紙條多米 11-06 決定拿掉。

## 玩起來長怎樣

- 短短一吹：晃一下。
- 慢慢吐長一點：波紋從下往上推過整團，顏色變清透、開始發光。不寫教學，也不顯示次數和分數。
- 牠示範，你跟著：牠先吸一大口、再補一小口，然後慢慢扁下去。研究裡的循環嘆息是一次慢吸、一次短吸、一次慢吐，原本討論寫的「吸兩小口」要照這個改。
- 吐過幾次長氣，牠安靜下來、瞇眼發光，你就知道可以停了。這條也防止有人一直用力吐到頭暈。
- 吐得短或吐不好，牠只是晃得少，不會變暗，也沒有失敗畫面（建議）。

## 這幾處跟原本討論不一樣

**麥克風權限的時機。** 原本寫「第一次對牠吹氣時才請求」，這做不到，沒有權限就偵測不到有人在吹。建議改成第一次按「呼吸」按鈕時請求。拒絕也沒關係，按鈕照樣能跟著牠脹縮。

**麥克風什麼時候開。** 建議按了呼吸才開，一分鐘沒動靜自動關。一直開的話畫面上方的橘點會一直亮，跟「只偵測、不錄音」的說法打架，也耗電。代價是多按一下，所以按鈕要一直放在畫面上。

**按鈕和替代方案要先做。** 討論裡的「現在的呼吸按鈕」和「已經做好的含小東西」其實都還在排隊。呼吸按鈕要跟吹氣一起做。含小東西要有半透明的皮才成立，皮 A、B 還沒選，收藏感先不算在這次裡。

**不方便吹的時候。** 跟著牠脹縮是同一種練習，少了你推動牠的那份回饋。原本寫「效果一樣」，沒有人量過，不講這句。

## 最大的風險：慢慢吐，麥克風可能聽不到

設計獎勵的是慢慢吐，可是吐得越慢氣流越弱，訊號越小。麥克風在手機底邊，拿著看畫面時不一定對著嘴，捷運上環境音可能蓋過吐氣。只看音量也不行，講話、關門都會觸發。

還有一個問題：牠自己的音效和背景音樂會被麥克風收進去。建議麥克風開著時把音樂降到很小。

做法（建議）：只在手機上算，不存、不傳。看低頻能量、頻譜夠不夠平（氣流像白噪音，講話有明顯的音高），再加持續時間。開麥克風的前半秒量環境音當基準。

## 先量再做

第一步做一個獨立的測試頁，不動遊戲本體，只顯示氣流讀數。多米用 iPhone 在下面三個地方各試一次：

| 地方 | 慢慢吐 10 次 | 用力吹 10 次 | 講話 30 秒 | 放音樂 30 秒 |
|---|---|---|---|---|
| 安靜房間 | | | | |
| 辦公室 | | | | |
| 捷運 | | | | |

暫定門檻（Agent 取的，多米可改）：慢吐和用力吹各抓到 8 次以上；講話、音樂各誤判 1 次以下。

| 結果 | 下一步 |
|---|---|
| 慢吐在三個地方都分得出來 | 開始做牠的反應 |
| 只有用力吹分得出來 | 改成用力吹一口起波紋，慢吐交給呼吸按鈕跟著做 |
| 網頁版分不出來 | 先別放棄，做一個 Swift 測試版再量一次。iOS Safari 開麥克風時可能強制套用人聲處理，關不掉，吐氣聲可能被當雜訊濾掉；原生的 app 可以改音訊模式。這條要等多米開口發 TestFlight 才量得到 |

測試頁的門檻只回答「聽不聽得到」。好不好玩要等牠的反應做出來，找沒看過的人試。

## 研究能講到哪裡

查了原文：Balban 等人，Cell Reports Medicine，2023。108 人，主要是 Stanford 大學部學生，全程遠端，每天 5 分鐘、連續 28 天。

| 查到的 | 對這個提案的意思 |
|---|---|
| 循環嘆息提升正向情緒比正念冥想多，呼吸頻率也降得比較多 | 原本討論這句成立 |
| 練一次之後，兩組焦慮都有降，幅度差不多（循環嘆息 −3.85、正念 −3.95） | 不能說它降焦慮比冥想好 |
| 作者寫最低有效劑量還不知道 | 撐不起「十秒就有用」，原本那句要拿掉 |
| 研究一開始是探索性質，事前沒有登記；排除了中重度精神或身體疾病的人 | 不能套到正在發作的焦慮症患者身上 |
| 練的是呼吸，沒有 app 也沒有果凍 | 這個 app 的效果沒有人測過 |

建議：宣傳講「對牠吹氣，牠會起漣漪」就夠了。不寫「科學證實」，不寫療效，也不引用這篇當 app 的證據。上架描述和隱私資訊只講麥克風怎麼用。
