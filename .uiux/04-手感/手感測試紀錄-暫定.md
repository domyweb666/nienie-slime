# 手感測試紀錄｜捏捏史萊姆

> 手感不能問，要量和看。Agent 只整理數字；判斷由真機和新的手決定。
> 不算數：模擬器、網頁版、多米自己捏（要標「自測，非盲測」，不能拿來過閘）。

## 測試前準備

- [ ] 原型裝上真機（見 技術選型決定-暫定.md 的可行路線）
- [ ] 買一盒真的史萊姆或麻糬捏捏樂（對照組）
- [ ] 找測試者：沒看過這個原型、不知道你改了什麼
- [ ] 借到你要支援的最舊 iPhone

## 五種測法

1. **延遲**：用 iPhone 240fps 慢動作，同時拍手指和螢幕，逐格數「手指碰到」到「史萊姆開始變化」隔幾格。每格約 4 毫秒，精度約一格。**先把延遲壓穩，再調彈性和觸覺。**
2. **最差機器**：最舊的 iPhone、開低電量模式，做最大幅度的捏和拉，記有沒有掉幀、在哪個動作掉。
3. **盲測**：一次只改一個參數，做成「1 號」「2 號」，各捏一分鐘，只問「哪一個你想多捏一下」。
4. **行為測試**：只說「你可以玩玩看」就走開。分兩段記錄：前十秒、到三分鐘。記他做了什麼，不記他說了什麼：捏多久才放下、有沒有笑或出聲、放下後有沒有又拿起來。
5. **和實物並排**：真史萊姆和手機輪流摸，問他、也看他：手機版贏在哪、輸在哪。

## 判讀

- 前十秒好、三分鐘掉 → 習慣化了。需要的是「變化」，不是「更強」。
- 「很像真的，但不好玩」→ 跟實物並排找差異，常見原因是每次反應都一模一樣。一次只加一種隨機（音高、偶發特別回彈）。
- 盲測多數人分不出 → 可以留，但要記成「沒變差」，不是「變好」。
