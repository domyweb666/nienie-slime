# 參數表（暫定）｜捏捏史萊姆

> 2026-10-31 初版，手寫到 v2.8（2026-11-01）就停了。2026-11-03 改成用程式從網頁版 `prototype/web/index.html` 的 `PRESETS` 和面板清單 `F` 產生，對到 v2.26；v2.23 那次拿 Swift `FeelParams.swift` 的黏土預設逐項比過，116 個都一樣（Swift 沒有 beta，固定 0），v2.24 新增與改動的 17 個（camGrip、camPad、pressLocal、leanAmp、leanMove、nuzAmp、gazeAmp、dodge、rubSpeed、tickRev、tickSeg、tickFree、reachV、bodySize、camFill、followZone、flinchAmp）也比過。
> 所有數字都是**待調**的起點，到現在還沒有一個參數做過盲測。調法：一次只改一個，Swift 面板「存 1／存 2／切 1／切 2」盲測（見手感測試紀錄），「複製數值」把定案的貼回來，網頁 `PRESETS` 和 `FeelParams.swift` 兩邊一起改。
> 單位：R ＝ 身體半徑（手機上約 80 到 100 點）；「每小步」＝ 1/240 秒。v2.23 起畫面上選的是史萊姆，材質是那隻的預設（第一節），面板「材質」按鈕可以換。
> 要重新產生：網頁 PRESETS 或 F 改過之後，請 Agent 照這份的格式重跑（腳本思路：抽 PRESETS、F、SLIMES，三種材質並排，跟 FeelParams 的黏土比）。

## 注意

- 延遲高時，處理延遲，不要去調回彈時長。延遲和時長是兩件事。
- 震動不是越多越有感：一秒震幾十次會手麻，感覺也會失效。質地微震跟手指移動綁死、手停就停，跟每幀都震的那種不一樣，但手麻的回報照記。
- 彈簧、觸覺的 iOS API 名稱寫進程式前要再查證（書的查證日期 2026-10）。
- 盲測做法：存 1（對照）→ 套一條候選 → 存 2 → 切 1／切 2 各捏一分鐘，問「哪一個想多捏」。一次只套一條。build 89 之後的版本，舊的存 1／存 2 少了新參數也讀得回來（缺的用現在的值補）。
- 舊版這張表手寫的「依據」欄（哪條是多米加的、哪條是提案第幾條），面板說明裡大多有寫；更早的脈絡在 git 歷史 `git log -p -- .uiux/04-手感/參數表-暫定.md`。
