# 技術選型決定（暫定）｜捏捏史萊姆

> 決定欄要多米在最舊機＋低電量實測後親口確認才寫。目前只有候選與可行路線。

## 目前候選

- **Swift＋Rive**（多米 2026-10-31 選擇試用）：Rive 負責 2D 變形骨架與畫面，Swift 負責觸控、彈簧、觸覺、聲音。
- 已試過、手感未達標的網頁原型（不算數，只當參考）：網子軟體 v7、MPM 黏土版。

## Rive 能做到的（查證於 2026-10-31）

- iOS runtime 用 Swift Package 安裝，支援 iOS 14 以上，有 SwiftUI 元件可用。
- 狀態機的監聽器支援手指按下、放開、移動、拖曳等事件，也有讓物件跟著手指走的動作。
- Rive 有用 Luau 寫的腳本功能。
- 未查證：網格與骨頭綁定的細節、腳本能不能逐幀改骨頭位置、在 iOS runtime 是否支援腳本。實作前要對照官方文件。

## 可行路線：沒有 Mac，怎麼把原型裝到 iPhone（查證於 2026-10-31，來源見對話）

所有路線都要先加入 **Apple Developer Program（每年 99 美元）**。自 2026-04-28 起上傳需用 Xcode 26 以上與 iOS 26 SDK。

| 路線 | 費用 | 怎麼做 | 限制 |
|---|---|---|---|
| 租雲端 Mac（如 MacinCloud） | 月租約 25 美元，或每天約 4 美元 | 遠端桌面操作 Xcode，自己簽名、上傳 | 遠端操作比較卡；自己處理簽名 |
| Codemagic | 每月 500 分鐘免費，之後每分鐘約 0.095 美元 | 寫建置設定檔，自動建置後上傳到 TestFlight | 要設定簽名與 App Store Connect API 金鑰 |
| GitHub Actions 的 macOS 機器 | 每分鐘約 0.062 美元 | 同上 | 同上 |
| 安裝到手機 | 免費 | 透過 TestFlight App 安裝，內部測試者最多 100 人 | 外部測試者的第一個版本要經過 App 審核 |

**不能替代的**：模擬器不播觸覺、沒有手指遮擋、延遲也不同，模擬器上順不代表手機上順。網頁版也不算數。
