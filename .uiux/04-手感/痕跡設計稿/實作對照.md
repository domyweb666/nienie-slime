# 按壓與拉扯痕跡：設計稿怎麼搬進 app

設計畫布五張：現況 v2.63、A 軟糖凹、B 壓薄透光、C 水面漣漪、D 只看外形。畫布上的效果是 `project/jelly-demo.js` 用 2D canvas 疊漸層畫的，數字都在那支檔裡，下面列的是同一組數字，換成 `JellySkin.metal` 的寫法。

長度單位：`R` 是身體半寬（設計稿 110px，app 裡就是傳進 `render` 的 `rpx`）。時間單位是秒。

---

## 現況為什麼難看（看 `JellySkin.metal` 得出來的）

`H1()` 把每個凹痕當成高度場上減掉一個高斯（`h -= d * 0.24 * exp(-|q|² * 1.6)`）。之後 `jelLight()` 拿 `H1` 的差分算法線，這個法線同時被四個地方用到：

- `dif` 打光：凹的左上那面背光，變一圈深色。
- `glow`（`tr` 那項）：凹的右下那面朝下，亮一彎。深色環加亮邊就是錄影裡的甜甜圈。
- `refr`：`ro = (-n.x, n.y) * rpx * refr`，凹痕邊緣斜率大，背景被推開很遠，凹裡看到的是錯開的另一塊背景，就是重影和「兩個圓疊在一起」。
- `spec`、`sheen`、`wet` 的第二顆亮光：凹的斜面上會冒出零碎的小亮點。

深色和紅色的身體 `cCore` 本來就暗，`dif` 壓下去的那一圈對比最大，所以黑糖、莓果最明顯。

拉扯時的暗色直條：拉長的那段很細，`B2`（大模糊）在細的地方兩側掉得很快，`gx/gy` 裡 `0.55 * B2` 那項讓法線沿著兩側往外倒，`dif` 打出一條暗邊，`refr` 在兩側往反方向推，中間就出現錯開的背景。凹痕若還沒被判定成拉扯（拖不到 0.4R），它跟著粒子走，看起來也像被拉成長條。

馬賽克小色塊：沒辦法從程式碼確定。推測是 `ro` 在斜率很陡的地方（凹痕邊、細頸兩側）取樣到房間貼圖很遠的位置，或 v2.61 網格遮罩在細的地方膠囊接不起來。驗法：隱藏面板把 `refr` 關掉看還有沒有，再把 `dent` 關掉看一次。下面「五版都要先做的」第 1、2 條做完，前一種原因會一起消失。

---

## 五版都要先做的（D 版只做這部分）

1. `H1()` 不再減凹痕。凹痕改成顏色層，畫在 `jelLight()` 的 water 混色之後、`cLine` 描邊之前。法線、折射、亮光都不受凹痕影響，甜甜圈、重影、零碎亮點一起沒了。
   ```metal
   static float H1(...) { return 0.45 * smoothstep(0.0, 1.0, B1.sample(sm, uv).r); }   // 舊的留在 markStyle 0
   ```
2. 細的地方壓低大模糊的法線項和折射：
   ```metal
   float b2 = B2.sample(sm, v).r, thick = smoothstep(0.08, 0.8, b2);    // 往前移，在算 gx gy 之前
   float kB2 = 0.55 * smoothstep(0.10, 0.45, thick);                   // 原本固定 0.55
   ...
   float2 ro = ... * smoothstep(0.05, 0.35, thick);                    // 細頸裡不推背景
   ```
3. 身體被按時往四周撐開（v2.16 的 press2）照舊，不用改。
4. 亮光被手指推開：只推算高光用的法線，不動 `dif` 和 `refr`。
   ```metal
   // q = (像素 - 凹痕中心) / 凹痕半徑，d = 這個凹痕現在的深度
   float2 away = normalize(q) * 0.35 * d * exp(-dot(q, q) * 0.6);
   float3 ns = normalize(n + float3(away.x, -away.y, 0.0));            // 只給 nh、H2 那兩行用
   ```
   設計稿的數字：亮光往外滑 22px（0.2R），被推的方向壓扁到 72%，推的範圍 95px（0.86R）的高斯。
5. 拉扯時亮光跟著拉長：app 的亮光是從遮罩模糊出來的法線算的，身體拉長它就跟著長，不用另外做。

Swift 這邊：`FeelParams` 加一個 `markStyle`（0 = v2.63 現況，1 A，2 B，3 C，4 D），面板「按壓與記形」一條滑桿，候選加「v2.63 對照」把它設 0。

## 要加的 uniform

`LightU` 全是 `float4`，Swift 端按順序 append。加在 `k4` 後面，前面的位置都不動：

```metal
float4 uD2[6];    // 每個凹痕的第二組：x 放手後幾秒（按著時 -1），y 漣漪 1 的時間，z 漣漪 2 的時間，w 漣漪 1 的強度
float4 uPull0;    // 拉扯：細頸根部 B.xy、尖端 T.xy（像素，y 向下）
float4 uPull1;    // x 拉長量 s（0…1），y 淡出係數 fade，z markStyle，w 漣漪 2 的強度
float4 cSat;      // B 版用：身體色飽和度 +25%、明度 +10%（Swift 算好給）
```

`uD[i]` 還是 `x, y, 半徑, 深度`，深度改成下面每版自己的時間曲線（Swift 端算）。

Swift 端（`SlimeRig`）要多給的：
- `DentView` 加 `rel`（放手後經過的秒數，按著時 -1）和漣漪時間。`Dent` 類別記放手時刻。
- 新的 `PullView`：被抓的那個粒子現在的位置當 T；根部 B 取那個粒子靜止位置往身體中心縮到 45%，再加上身體中心位移的一半；`s = 那個粒子離靜止位置的距離 / 1.3R`，夾在 0 到 1。放手後照樣每幀算（形狀退回去 s 自己會變小），另外乘各版的淡出係數。
- `SlimeView` 第 847 行附近把 `PullView` 轉成螢幕座標，跟 dents 一起傳進 `JellySkin.render`。

細頸的遮罩（A、B、C、現況都會用到）：
```metal
float2 P = v * res, B = uPull0.xy, T = uPull0.zw, BT = T - B;
float hN = clamp(dot(P - B, BT) / max(dot(BT, BT), 1.0), 0.0, 1.0);
float dN = length(P - (B + BT * hN));                       // 離細頸中軸多遠
float2 u = normalize(BT), nL = float2(-u.y, u.x);
if (dot(nL, float2(-0.6, -0.8)) < 0.0) nL = -nL;          // 法向取朝光那一側
float pk = uPull1.x * uPull1.y;                              // 拉長量 × 淡出
```

先做一層五版共用的底子：拉長那段本來就比較薄，`thick` 乘 `1 - 0.22 * s * exp(-(dN / 0.4R)²)`。app 的 absorb 已經讓薄的地方比較透，這層只是讓細頸別比身體深。

## A 軟糖凹

按下去：很淺很寬的凹，不畫深色環。只在凹的右下畫一道細亮邊，左上一片很淡的陰影，亮光被推開往旁邊滑。放手彈回時亮邊閃一下。
拉起來：拉長那段變薄、顏色變淡、更透出背景，沿著拉的方向一道長光澤線，像拉太妃糖。

| 項目 | 數字 |
|---|---|
| 凹痕半徑 | 82px，0.75R |
| 沉下去 | 指數趨近，τ 0.028 秒（80ms 到九成五） |
| 放手彈回 | 彈簧 ω 19、阻尼比 0.5，0.35 秒內看不出來，過頭約兩成 |
| 左上陰影 | 中心往左上偏 0.22r，半徑 0.85r，最深 7.5%（陰影色），往外淡到 0 |
| 右下亮邊 | 圓心往右下偏 3px，半徑 0.6r，角度 -0.35 到 1.95 弧度（畫面座標，0 朝右、往下為正），兩端用 sin 淡掉；細線 1.8px、強度 0.5×深度；外面一層 12px 柔光、強度再乘 0.16 |
| 放手閃一下 | 放手後 0.13 秒最亮，寬 0.07 秒的高斯，強度 +0.5，半徑同時放大 8% |
| 拉扯變透 | 細頸範圍：沿中軸長 0.55L、寬 0.42R×(1 - 0.35s)；`thick` 再乘 `1 - 0.55·pk·遮罩` |
| 拉扯變淡 | 同範圍疊身體淺色（cCore）10% |
| 光澤線 | 從根部往前 10% 到尖端前 0.22R，往朝光側偏 0.13R×(1 - 0.4s)；細線 2.4px 強度 0.78，柔光 9px 強度 0.16；頭尾 22% 淡入淡出 |
| 放手恢復 | 淡出 exp(-t / 0.13)，0.4 秒看不見 |

shader：
```metal
// 按壓（每個凹痕）
float2 q = (P - uD[i].xy) / uD[i].z;  float d = max(uD[i].w, 0.0);
float2 qs = q + 0.22;                                               // 陰影中心往左上
c.rgb *= 1.0 - 0.075 * d * exp(-dot(qs, qs) * 1.4);
float rel = uD2[i].x, fl = rel < 0.0 ? 0.0 : exp(-pow((rel - 0.13) / 0.07, 2.0));
float rr = 0.6 * (1.0 + 0.08 * fl), lq = length(q - 3.0 / uD[i].z);
float ph = atan2(q.y, q.x), arc = sin(3.14159 * clamp((ph + 0.35) / 2.3, 0.0, 1.0));
float rim = (exp(-pow((lq - rr) * uD[i].z / 0.9, 2.0)) + 0.16 * exp(-pow((lq - rr + 5.0 / uD[i].z) * uD[i].z / 6.0, 2.0))) * arc;
c.rgb = mix(c.rgb, float3(c.a), clamp(rim * (0.5 * d + 0.5 * fl), 0.0, 1.0));
// 拉扯：thick 那行之後
float neckM = exp(-pow(dN / (0.42 * rpx * (1.0 - 0.35 * uPull1.x)), 2.0)) * smoothstep(0.0, 0.15, hN);
thick *= 1.0 - 0.55 * pk * neckM;
// 光澤線：水混色之後
float dl = abs(dot(P - B, nL) - 0.13 * rpx * (1.0 - 0.4 * uPull1.x) * mix(1.0, 0.6, hN));
float along = smoothstep(0.1, 0.25, hN) * (1.0 - smoothstep(0.75, 0.95, hN));
c.rgb = mix(c.rgb, float3(c.a), clamp((0.78 * exp(-pow(dl / 1.2, 2.0)) + 0.16 * exp(-pow(dl / 4.5, 2.0))) * along * pk, 0.0, 1.0));
```

## B 壓薄透光

按下去：手指底下那塊被壓薄，變亮變透，周圍被擠開的一圈比較濃（偏飽和色，不是黑），像按水球。放手那一圈往外漾一下再散。
拉起來：拉長那段兩側邊緣保持濃，中間變透變亮，像拉長的軟糖。

| 項目 | 數字 |
|---|---|
| 壓薄範圍 | 半徑 58px，0.53R |
| 沉下去 | τ 0.06 秒 |
| 放手 | τ 0.09 秒退 |
| 變透 | `thick` 乘 `1 - 0.6·d·遮罩`（柔邊圓，中間 100%、半徑一半處 85%、邊緣 0） |
| 變亮 | 同範圍疊 cCore 22% 再疊白 14% |
| 濃的一圈 | 半徑 0.77R（壓薄半徑 ×1.45）；cSat 在 0.7 倍半徑處 32%、0.86 倍處 14%，內外淡到 0 |
| 放手漾開 | 0.5 秒；半徑從 1 倍長到 1.75 倍（先快後慢，1-(1-t)²），強度 0.3×放手時深度×(1-t)^1.4，帶一點白（35%） |
| 拉扯中間變透 | 細頸寬 0.3R×(1 - 0.3s)，`thick` 乘 `1 - 0.72·pk·遮罩`，再疊白 16% |
| 拉扯邊緣變濃 | 邊緣色 cEdge 往 cSat 混 0.55·pk，邊緣那層濃度 ×(1 + 0.5·pk) |
| 放手恢復 | exp(-t / 0.13)，0.4 秒 |

shader：變透和變亮都放在 water 分支裡，在算 `T` 和 `w` 之前把 `thick` 改掉，這樣透出來的背景跟身體其他地方用同一個折射，不會錯開。濃的一圈：
```metal
float lq = length(q) / 1.45;
float ring = 0.32 * d * exp(-pow((lq - 0.72) / 0.1, 2.0));
c.rgb = mix(c.rgb, cSat.rgb * c.a, ring);
// 放手漾開：t = uD2[i].x / 0.5
float R2 = 1.0 + 0.75 * (1.0 - (1.0 - t) * (1.0 - t));
c.rgb = mix(c.rgb, cSat.rgb * c.a, 0.3 * d0 * pow(1.0 - t, 1.4) * exp(-pow((lq / R2 - 0.8) / 0.08, 2.0)));
```
`d0` 是放手那一刻的深度，Swift 端記住、塞進 `uD2[i].w`。

## C 水面漣漪

按下去：極淺的凹，加一圈淡淡的亮光漣漪從指尖往外擴，0.5 秒散掉；按住時每 1.2 秒再漾一圈更淡的。放手凹馬上平。
拉起來：沿拉的方向 2 到 3 條很淡的亮色流線，像水被拉出的紋，放手 0.5 秒淡掉。

| 項目 | 數字 |
|---|---|
| 凹的陰影 | 半徑 60px（0.55R），中心往左上 10px，最深 4.5% |
| 沉下去／放手 | τ 0.04 秒／τ 0.025 秒 |
| 漣漪 | 0.5 秒；半徑 r×(0.25 + 1.25×(1-(1-t)^2.2))；強度 a×(1-t)^1.6；細線 2.2px 到 1.1px，外層 7px 柔光、強度 ×0.22；圈是橢圓，高 = 寬 ×0.9 |
| 漣漪強度 | 按下那一圈 a = 0.5，按住後每 1.2 秒一圈 a = 0.26 |
| 流線 | 三條，離中軸 -0.2R、0.02R、0.2R（拉越長越往中間收，×(1 - 0.35s)），到尖端收到 45%；強度 0.2、0.3、0.17；細線 1.6px，外層 6px、強度 ×0.25；稍微往外彎 |
| 放手恢復 | 線性淡出 0.5 秒 |

shader：漣漪是兩個環（`uD2[i].y`、`.z` 是它們的時間，超過 0.5 不畫），同一個公式：
```metal
float t = uD2[i].y / 0.5;
float rad = 0.25 + 1.25 * (1.0 - pow(1.0 - t, 2.2));
float lq = length(float2(q.x, q.y / 0.9));
float px1 = (lq - rad) * uD[i].z;                                        // 換回像素
float ring = uD2[i].w * pow(1.0 - t, 1.6) * (exp(-pow(px1 / (1.1 * (1.0 - 0.5 * t)), 2.0)) + 0.22 * exp(-pow(px1 / 3.5, 2.0)));
c.rgb = mix(c.rgb, float3(c.a), clamp(ring, 0.0, 1.0));
```
流線：對三個偏移各算一次到偏移後中軸的距離 `dl`，`(0.25·exp(-(dl/3)²) + exp(-(dl/0.8)²)) × 強度 × pk × along`，along 同 A 版。

## D 只看外形

身體裡什麼都不畫。按壓只有身體被撐寬、亮光被推開；拉扯只有形狀和亮光跟著拉長。只做「五版都要先做的」那五條，`markStyle = 4` 時其他層全部跳過。

## 現況 v2.63（對照組）

設計稿上這張是照錄影仿的，數字只是為了看起來像：深色環在凹痕半徑 0.62 到 0.8 處 55%、38%，右下亮邊 60%，往右下錯開 (17, 11)px 的第二個淡環，凹裡取樣錯開 (-20, -14)px 的背景 50%，放手 1.5 秒線性淡；拉扯時一條深色長橢圓 62%、兩條深色直條 38%、四塊 6px 色塊每 0.12 秒換位置。app 裡 `markStyle = 0` 就是現在的程式，不用另外做。

## 網頁版

`prototype/web/index.html` 的 WebGL 皮（`jelInit`）跟 `JellySkin.metal` 是同一套寫法（y 方向相反，見 metal 檔開頭的註解），選定之後兩邊照同樣的數字改，面板也放同一個 `markStyle`。
