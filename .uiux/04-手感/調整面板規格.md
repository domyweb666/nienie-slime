# 調整面板規格 v1（v2.52，2026-11-22）

> 照《虛擬手感》3-4 第十一節。兩邊各一份實作：網頁 `prototype/web/desk.js`，手機 `ios/NieNie/UI/FeelDeskModel.swift`（邏輯）＋ `FeelDesk.swift`（畫面）。名字、範圍、匯出的格式兩邊要一樣，改一邊就改另一邊。

| 欄 | 內容 |
|---|---|
| 1 位置 | 右下角「調」按鈕打開，蓋在天空上，牠在下面照樣捏得到。App Store 版本不顯示按鈕（TestFlight、開發版照舊），隱藏面板（長按標題）裡有入口 |
| 2 旋鈕 | 主旋鈕 7 條，一個底層詞一條：軟 `alpha`、黏滯 `lag`、留形 `creep`、回原形 `recover`、彈：晃幾下 `inertiaZ`、彈：晃多快 `inertiaHz`、韌 `maxPull`。每條有換算（幾毫秒、幾秒退一半）、參照手勢、三種材料的值、被蓋掉時的「實際是 X」。「韌的另一半」是黏條開關。「更多」：`pressSink`、`yield`、`slide`、黏手 `stick`、流 `flow` |
| 3 比較 | 盲比：兩格存檔隨機叫 1 號、2 號，先給哪個也隨機，比的時候畫面上沒有數字，選完才揭曉，自動記一行（日期、材料、差在哪、先摸哪個、換幾次、幾秒、選了誰、題目） |
| 4 存與還原 | 3 格存檔；一份存檔是起點材料＋13 個數字（12 條旋鈕＋黏條）。換的時候不加任何動作。存檔記預設版本（`v2.52`）和三種材料預設值的指紋；預設改了會問「用新預設／留著我的」，沒回答下次再問。上次留在台上的數字下次打開會回來 |
| 5 量測 | 灰盒、純圓、延遲測試（手機）、每個圖層一個開關、亂捏測試（手機按鈕；網頁用 `fuzz.js`）。讀數：更新率、最長一格、整格毫秒、物理毫秒、保險作用的格數比例、擺飾透過身體的毫秒（手機）。這一組不存 |
| 6 匯出 | 「複製數值給 Agent」：第一行 build、預設版本·指紋、機型、更新率、低電量；再來材料、各旋鈕（韌寫實際值）、存檔位、這次動過哪幾條、最近 5 行盲比；最後一行 `#nienie-feel {…}` 給程式讀。「貼上匯入」讀那一行，數字和三格存檔原樣回來，手機和網頁互通 |
| 7 正式版 | 手感定案後，把定案的數字寫回 `PRESETS`／`FeelParams` 的預設，換 `FEELVER`／`FeelKnob.version`；上架版本沒有「調」按鈕 |

存檔的位置：網頁 localStorage `nienie.feel`，手機 UserDefaults `nienie.feel`，格式 `{v:2,pv,ps,base,k,s,log}`。v2.39 到 v2.51 的舊格式會自動搬成存檔 1、2。
