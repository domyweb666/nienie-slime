# 芋圓手感極致計畫（暫定）

> 2026-11-07 深夜，多米定：一隻為主，留芋圓。「只留一隻，那這隻的手感就要好好研究怎麼讓他極致了。」
> 這份接在 `手感研究與基準-暫定.md`（11-06）後面：那份給了基準表 v1 和研究依據，這份只講「只剩芋圓之後，照什麼順序把她做到極致」。

## 材質未定

多米 11-07：「芋圓的手感還待考慮，因為還不知道什麼手感最好。」所以黏土、麻糬、果凍三個都還在，v2.33 預設黏土只是佔位（總要有一個開起來的樣子），不是決定。面板「材質」三顆按鈕隨時切。

這句話把計畫的第一步換掉了：以前第一步是量延遲，現在第一步是先講清楚「最好」怎麼判斷，不然量到最後還是三個都不知道該選哪個。

## 怎麼知道哪個手感最好

研究那份（`手感研究與基準-暫定.md`）查到三件事，直接決定測法：

- 留形的被判得比彈回去的軟，但最軟的不等於最舒服，舒服有一個高峰就往下掉。
- 舒服度的個人差異比軟硬本身大（48 人那篇）。所以不會有一組對每個人都最好的數字。
- 問意見沒用，要看行為：捏多久才放下、放下後有沒有再拿起來。

所以「最好」我建議這樣定義：**沒摸過的人，沒人要求的情況下，捏最久、放下後最會再拿起來的那一個。** 不是你最喜歡的那個，也不是看起來最像史萊姆的那個。

測法（材質盲測，閘門 3 的性質，Agent 不能代測）：

| 項目 | 怎麼做 |
|---|---|
| 給幾個人 | 3 到 5 個沒摸過的人，加你自己一份當對照（你的不算分） |
| 用什麼 | build 117 的面板「存 1／存 2」各放一種材質，第三種用「材質」按鈕；順序每個人打亂，不告訴他哪個是哪個 |
| 每種多久 | 給 3 分鐘，說「你可以玩玩看」就走開，用眼角看 |
| 記什麼 | 每種：捏多久才第一次放下、放下後有沒有再拿起來、用幾根手指、最常做的動作、有沒有笑。不問好不好 |
| 怎麼算 | 每個人捏最久的那種記一票。3 個人裡 2 個投同一種，就是它 |
| 票散掉怎麼辦 | 代表個人差異壓過材質差異（研究說會這樣）。那就選留形中間的那種（麻糬），把留形多寡做成面板裡一條滑桿給之後的盲測，不開放給使用者選 |

測完才決定芋圓是哪種，然後基準表才有對象可以量。

## 先把三種都整理到可以比

盲測之前有一件事得先做，不然比不公平：三種材質只有黏土被真機捏了十幾輪，麻糬、果凍還停在 11-01 的參數。所以在盲測前，我把黏土這十幾輪修掉的東西（抽搐、交叉、鏡頭、從中間拉、凹痕）確認三種都有，手感層的 selftest（T45、T28、T36 本來就三種都量）全過，再給你。不調手感，只補齊。

## 一隻為主改變了什麼

基準表沒變，變的是對象。以前每條都要三種材質各量一次，現在只量芋圓。個性層（四隻的 restMul、trRate 那些）留著不動，底部那排收進面板，想比對再開。

另外一件以前沒有的：芋圓的個性是「怕生，熟了很黏人」（熟得慢 0.7 倍、戒得快 1.6 倍、比較少主動來找你）。熟跨天留下來之後，這個個性會變成好幾天的過程：第一天碰她會縮，第三天她會貼過來。這也是手感的一部分，像摸貓。
