## 先講拿掉碗會動到什麼

拿掉石頭盤、盆栽很簡單，面板「桌上的擺飾」設 0 就沒了。

碗不一樣。碗是牠的家，網頁 `index.html` 有 80 行跟碗有關，selftest 45 行，Swift 有 5 個檔案用到。要換掉的有：

| 現在靠碗的 | 拿掉碗以後 |
|---|---|
| 牠的家（休息時待的位置，浮在碗上方） | 坐在窗台正中間，底部貼著窗台、稍微壓扁一點，像一顆麻糬放在木板上。建議墊一塊亞麻小布墊（下面清單第 1 件），不墊也可以 |
| 爬出碗、在窗台上走（envRoam） | 直接在窗台上走，少了「爬出來」那段 |
| 走路回家：從窗外翻過碗後緣進碗 | 從窗外翻過窗框下緣，落到窗台上 |
| 興奮時進碗小跳 | 落到窗台時小跳 |
| 覓食提案的「敲碗叫牠回來」 | 改成敲窗台（點窗台兩下）。提案本來就寫了「點窗台也當成敲碗」，改起來很順 |
| 碗擋住牠的下半身 | 沒有了。整團都看得到、都捏得到，這是拿掉碗最大的好處 |

所以拿掉碗是一片完整的工：網頁改完跑 selftest 三輪，Swift 照規矩等 build 117 回報完再搬。

## 擺飾的四條規矩

1. 不擋牠。窗台正中間留給牠，擺飾只放兩端，高度不超過牠身體的一半。牠會長大（見 `長大提案-暫定.md`），要照最大的時候留位置。
2. 窗台上同時最多兩件。走路帶回來的東西一天最多三件，也放窗台上，擺飾太多會跟它們搶。
3. 跟牠的生活有關的優先。每件擺飾最好能做一件事：被搖會晃、晚上會亮、記錄牠長大。純裝飾的放最後。
4. 顏色讓開。芋圓是紫色，擺飾避開紫、粉紫、藍紫；窗外是綠的，綠色擺飾最多一件。用奶油白、燕麥色、淺木、霧面白陶、一點點鼠尾草綠。

不建議放的：碗、盤子、食器（暗示要餵牠）；時鐘、日曆（暗示天數、連續紀錄）；有人的照片；第二盆植物（跟窗外的綠撞）；亮面玻璃球、鏡子（反光太強，搶牠的亮光）。

```

畫一個單獨的物件，透明背景 PNG，1024×1024，物件置中、佔畫面約六成。
鏡頭正面、稍微俯視約 10 度，跟附圖的窗台同一個角度。
```
