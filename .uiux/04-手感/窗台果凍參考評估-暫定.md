# 窗台果凍原型的評估（2026-11-06）

對象：`Downloads/史萊姆參考/` 的網頁原型與 4 張圖，跟 v2.27（build 101）對照。

我的判斷：拿它的外觀、窗台和新玩法，不拿它的身體。身體留我們這套，已經真機改過十幾輪；參考版的身體撐不起多米要的手感。

怎麼驗的：拖、兩指拉斷是我在瀏覽器用模擬手指實際跑的，有截圖。餵煩惱、呼吸、含東西、黏窗只讀了程式，沒跑過。兩邊的手感和手機效能都沒有驗過。

## 建議拿的

**1. 果凍皮。** 這是看起來差最多的地方，也是多米說「畫風不適合」的解法。它只動畫面，不動物理，舊的回歸測試不受影響。

不能照抄它的算法。它的畫法要把每顆粒子傳進 shader，上限 64 顆，我們有 518 顆。改法：把現有外框畫成遮罩，模糊後當高度，算法線再打光。外框線也不用畫了，黏土亂玩留下的 1 到 3 處互疊應該會看不出來（待驗）。

手機版現在用 CAShapeLayer，要換成 Metal。閘門 3 從來沒量過，這片做完一定要量。手機跑不動的退路是用漸層和模糊圖層疊，質感會差一截。

**2. 窗台、碗、窗外天空。** 有家才像寵物，v2.19 拿掉影子時那個「空間前後矛盾」也一起解決。要付的代價在下一節。

**3. 眼睛和腮紅。** 那張四隻角色圖的可愛幾乎都在臉上。v2.27 才拿掉眼睛，手機版面板「眼睛 v2.23」設 1 就回來，形狀要重調。腮紅碰到不做清單的「眼睛以外的表情」，要多米點頭。

**4. 兩指拉斷、爬回來黏好。** 目前手勢裡沒有這種大回饋。只給兩指，單指照舊拉長，這樣不會跟「拉很長」打架。

**5. 餵煩惱和一起呼吸。** 幾乎不碰物理，風險最低，而且是把玩具變成每天會用的東西的那一步。吃掉就真的刪、不存檔這點要照做。

**6. 含小東西、黏窗戶。** 排最後。含東西要有半透明皮才成立，黏窗要先有重力。

## 不建議拿的

- 它的身體。拉 2 個半徑就斷、2.4 秒甩回圓，都跟多米 build 53、build 59 的回報相反（要拉很長、回彈太快）。粒子只有 37 顆，也做不出手指底下那塊的凹痕和皮膚被帶著走。
- 即時合成音。10-31 就放棄過，v3 ASMR 多米也點頭了。
- 伸小手那段程式。C1、C2 已經有偽足碰手指，要改的只是長相。

## 要多米決定的衝突

| 目前的定案 | 窗台版要的 | 我的建議 |
|---|---|---|
| 懸空、沒有地面（10-31） | 重力和窗台 | 改成窗台，留面板開關切回懸空 |
| 鏡頭跟著走、拉多大退多遠（v2.13、v2.17） | 房間固定 | 先鎖鏡頭。牆是平的，之後要小幅退也做得到 |
| 上下左右遊走（v2.18） | 只能在窗台上 | 沿窗台走、跳，偶爾爬窗 |
| 黏土拉 7 個半徑 | 一個畫面放不下 | 上限先降到放得下的長度，捏過再調 |
| 8 條觸手（11-05 才選） | 圓的一團 | 多米 11-06 定了：圓身體、有臉，不要 8 條 |
| 黏土慢慢退 | 亮面果凍配慢慢退可能怪 | 不先改，換皮之後捏了才知道 |
| 印象只活在這次打開（v2.20） | 伴手禮、認識天數、長成你的樣子 | 這批不做，等窗台版捏過再談 |
| 不用 Rive | 對話裡建議用 Rive | 維持不用，參考原型證明程式算得出來 |

## 素材

- `極簡奶油牆面綠色窗景.png`：可以用。綠幕範圍 x 156 到 835、y 304 到 1131，邊緣乾淨。牆色上下左右都是約 #F2E7DC，幾乎沒有深淺差，補滿瘦長手機不會有接縫。窗台也貼著窗了。
- `極簡陶器與多肉盆栽靜物.png`：可以用，碗已經是霧面。要去背，底色約 #EDE8E4。要拆成三個檔。
- `溫馨窗台上的陶碗與綠植.png`：參考原型現在用的是這張舊圖，正式版不用。換底圖時碗、窗台的座標都要重量。
- `四款薄荷果凍史萊姆角色.png`：只當果凍皮的對照目標，身體是程式畫的，不會進 app。圖裡的地面陰影用程式補。
- 5 張天空先不用生，參考原型用程式畫，看起來夠用。要換再生。

## 靜態對照圖（2026-11-06）

圖在 `.uiux/04-手感/果凍皮對照/`，產生器是同資料夾的 `jelly-compare.js`。外框是引擎真的算出來的，打光用「外框遮罩模糊兩次當高度」，不是 metaball。

- 三種皮都能套在 518 顆粒子的現有外框上，亮弧會跟著拉長和壓扁變形，按住的凹痕也有打光。
- 窗台那張的「坐進碗裡」是示意，用算式把碗口以下收窄，還沒有碰撞。外形用 8 個種子裡最圓的種子 7。
- 「外框線不畫，互疊就看不出來」沒驗到：隨機亂拖 120 輪都沒拖出互疊，沒有畫面可比。
- 手機效能還是沒量。

## 施工順序

先網頁，每片都有面板開關可以切回去；舊 selftest 一律關新功能，新功能加新項目，連跑 3 輪。

1. 果凍皮加眼睛。先出 3 隻的靜態對照圖給多米挑，再做動態。
2. 窗台場景、重力、碗。這片最大，動到遊走、鏡頭和拉伸上限。
3. 兩指拉斷、爬回來合體。
4. 餵煩惱、一起呼吸。
5. 移植 Swift：皮換 Metal，量閘門 3。TestFlight 等多米開口。

多米 build 101 的回報不用等完才開工，第 1 片跟抓觸手那批問題不衝突；第 2 片之前要先定上面的衝突表。
