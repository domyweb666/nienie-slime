# 閘門 1：三個測試（多米帶回結果才算數）

> 2026-11-06。這三個都要真人，Agent 不能代測，多米自己試也不算。結果填回 `01-核心動作卡-暫定.md` 的「三個測試」。
> 找認識但沒看過這個 app 的人。每個人只能算一次，看過就不是新的眼睛了。

## 一、一句話測試（最快，5 分鐘）

**給幾個人：** 3 個。

**怎麼做：** 給他看 app 開著的畫面，只告訴他名字。問：「你覺得這是什麼時候會用的？」接著閉嘴，不解釋。

| 人 | 他說了什麼（照抄） | 有沒有講到「養」「陪」「寵物」「看牠」或差不多的意思 |
|---|---|---|
| 1 | | |
| 2 | | |
| 3 | | |

**怎麼算過：** 3 個裡有 2 個講到（11-07 定位改成寵物後換的判準，原本是「想讓手停一下」）。講到「捏捏樂」「紓壓玩具」代表畫面還在講舊定位，改畫面，不加文案。

## 二、實物測試（要花一點錢）

**要準備：** 一盒真的史萊姆或麻糬捏捏樂。這一步要多米自己買，我不代買。

**給幾個人：** 3 個。

**怎麼做：** 放在桌上說「這個給你玩」，然後去做別的事，用眼角看。不問感想。

| 人 | 用幾根手指 | 最常做的動作 | 捏多久才放下 | 放下之前發生什麼 |
|---|---|---|---|---|
| 1 | | | | |
| 2 | | | | |
| 3 | | | | |

**這個沒有過不過：** 11-07 定位改成寵物後改成對照用：看人怎麼捏一團軟的東西（手勢照這個來），還有捏多久會放下。手機版不用贏這盒。

## 三、只剩一個功能

**用哪一版：** 網頁版，面板收起來。走路、吹氣都不算在內，這題只測捏。

**給幾個人：** 3 個。

**怎麼做：** 手機交給他，說「玩玩看」，計時 2 分鐘。隔天問一句：「那個東西，你還想再玩嗎？」

| 人 | 2 分鐘內有沒有自己停下來 | 最常做的動作 | 隔天還想玩嗎（照抄） |
|---|---|---|---|
| 1 | | | |
| 2 | | | |
| 3 | | | |

**怎麼算過：** 門檻由多米定。我建議 3 個裡有 2 個隔天還想玩。

## 測的時候不要做

- 不要解釋這是紓壓用的
- 不要在旁邊教，看到他卡住也不要講話
- 不要問「好玩嗎」，禮貌的人都會說好玩

這三個測試是便宜的經驗法則，過了不代表一定好玩，沒過則值得停下來想。
