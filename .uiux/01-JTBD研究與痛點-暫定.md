# JTBD 研究與還沒被解決的痛點（暫定）

> 2026-11-25。多米問：人到底為什麼會用這種 app？照 JTBD 看，哪些痛點還沒人解決？要做哪些功能專門解決？
> 這份是桌上研究：App Store 評論、論壇、報導、研究論文，加上讀 repo（`feel-3x-panel-v1`，v2.59）。它把 `01-定位與JTBD-暫定.md` 裡「全部是想像」的情境，換成「有人在別的產品上這樣做」的假設。**這是二手證據，不是觀察，閘門 1 照樣過不了。** 要過，第九節的訪談要找真人做。
> 功能都是候選，不做清單由你逐條決定；標 ❓ 的我不替你選。

## 一、先講結論

1. **你的定位站得住，外面有一塊空位。** 寵物類 app 的人會被兩件事趕走：要照顧、會愧疚（通知、會死、會怨你），或摸不到、只能看（貓咪後院）。「摸得到，又不欠牠什麼」這個位置，我這次查到的產品沒有一個同時做到。
2. **「手癢」不成立，有外部證據。** 實體的指尖玩具可以一邊做事、一手無意識地玩，app 要你的眼睛，做不到。你 11-07 的判斷對，不要回頭跟捏捏樂比觸感。
3. **整個類別最大的共同痛點：讓人放鬆的東西，自己在打斷人。** 史萊姆 app 捏幾秒就跳廣告；睡前的雨聲半夜被廣告吵醒；寵物 app 用愧疚通知叫你回來。你已經全部避開（沒廣告、不推播、不懲罰），但上架頁和打開的前十秒要讓人看得出來。
4. **現在的 JTBD 有一條要改。** 「走完一段路回來，想看牠帶了什麼」是 app 的機制，不是使用者的處境：拿掉這個 app，這個處境就不存在。底下真正的處境是「回到自己的地方，想被迎接」，帶回來的東西是迎接時的驚喜。
5. **兩塊缺口在 app 外面：** 不打開也看得到牠（小工具、待機模式）；睡前的聲音接不住（現在鎖螢幕雨聲就停）。app 裡有兩件小事：第一下要抓得到；捏夠了要有個好的結尾。
6. **兩個時刻分工不同（我的判斷，訪談會驗）：** 「回到自己的地方」是別人選你、不選別人的理由，「縫隙」是一天會打開幾次的理由。只顧寵物感，打開次數撐不起來；只顧縫隙，你就是另一個史萊姆模擬器。

## 二、兩個 JTBD 用詞

- **第一次雇用**：在 App Store 決定下載。**每次打開**：又雇用一次。這類 app 幾乎都死在第二種：下載很容易，一週後就刪了。
- **四股力量**：推力（現在的做法哪裡讓人受不了）、拉力（新東西哪裡吸引人）、焦慮（換過去會怕什麼）、習慣（舊做法已經是反射）。後兩股是擋人的。

## 三、會雇用牠的三個時刻，加一個不會的

### 時刻 A｜縫隙：等東西、事情卡住、手已經伸向 IG

> 當我在等東西、事情卡住，或手已經要去滑 IG，我想要三十秒到兩三分鐘，盯著一個會回應我的軟東西換個檔，然後回去做我的事。

- 他們現在雇用：滑社群、看捏史萊姆的影片、手機小遊戲、史萊姆模擬 app。
- 證據：
  - 手機上大約四成的 app 開啟不到 15 秒，最常發生在家裡、一個人的時候（Ferreira 等，2014）。
  - Revealing Reality 的報告：18 到 24 歲有三成常看捏史萊姆的影片，65 歲以上只有 1%（紐西蘭先驅報轉述）。
  - 看 ASMR 影片時平均心跳下降（Poerio 的研究）。這是影片的研究，不能拿來講你的 app 有效。
  - 壓力球的隨機試驗結果不一：牙科 20 人沒差、血管攝影 120 人焦慮降低、碎石術 120 人跟聽音樂、什麼都不做比都沒差。跟核心動作卡的註記一致，文案別寫療效。
- 被開除的理由：
  - 史萊姆 app：捏五秒就一支廣告（Goo 的評論）；台灣 App Store 的中文評論一樣在講廣告；物理會卡進自己、質地都一樣（World of Slime 的評論）；下載一週就刪，膩了（Fidget Toys 3D 的評論）。我查到的幾個中文史萊姆 app 都是每週或每月訂閱。
  - 影片：只能看，下一支接著來。
- 牠現在有：沒廣告、跟手、會留形、ASMR 聲音、搖晃沉澱（搖亂、看牠靜下來，一個有頭有尾的小儀式）。
- 缺口：
  - 開場時第一下抓不到牠：`SlimeRig.swift` 1962 行，開場途中碰到，牠 0.25 秒回家，這一下不抓。這個時刻的人要的是「現在」。
  - 聲音是這個時刻的主角。對手是真實錄音的影片，你在 ASMR 聲音極致計畫裡也寫了：合成的再怎麼調，都像「很像史萊姆的聲音」。
  - 沒有「夠了」的結尾。你不會讓人無限滑，但也不會幫人停下來。

### 時刻 B｜回到自己的地方：下班到家、回房間、一個人待著

> 當我回到自己的地方、一個人待著，我想要有個活的、認得我的小東西過來迎接我、讓我摸一下，而且我不欠它什麼：不用餵、不用打卡、幾天沒來它也不會怎樣。

- 他們現在雇用：貓咪後院、Finch、小工具寵物（Widgetable 這類）、填充玩偶和捏捏、真的寵物。
- 證據：
  - Quartz 的評論文章認為，大人買捏捏多半是因為寂寞、缺少觸摸，不是為了消耗緊張。
  - 貓咪後院的貓自己來來去去，不依賴玩家（Kaleo 的介紹）。
  - Widgetable 的評論：有人說最近很難熬，每次打開手機看到小工具寵物說的話，幫了他很多。
- 被開除的理由：
  - **要照顧、會愧疚**：家長指南把「你的小狗好寂寞，快來玩」這種通知叫做情緒操弄（Screenwise）；Tamagotchi app 的通知多到評論者只好關掉（Digital Trends）；有人小時候的電子雞死掉以後，再也不敢碰照顧寵物的遊戲，連 Finch 也是（Unwinnable）。
  - **摸不到、只能看**：有玩家說貓咪後院很好，但有時想跟貓多一點主動相處的時間（GameSkinny）；收集完就沒事做（App Store 評論）。
  - **新鮮感退了**：Finch 一開始很可愛，幾週後有人覺得每天打開有點蠢（Habi 整理的評論）。
  - 小工具寵物：要看廣告才能補飼料（Widgetable 的評論）、付費項目很多。
- 牠現在有：不懲罰；熟跨天存起來（v2.34，網頁 `localStorage`、Swift `UserDefaults` 的 `nienie.imp`，真機沒驗）；眼睛；五個需求和心情（網頁 v2.41–42）；走路帶東西；擺飾會倒。
- 缺口：
  - 不打開就看不到牠。小工具寵物證明「打開手機就看到牠」本身就有人要，但現有的都是數值、飼料、廣告。
  - 「你不在時牠過了日子」還在提案（自己的生活）。
  - 不懲罰測試（三天沒開，第四天問「牠有沒有怎樣」）還沒做。

### 時刻 C｜關燈前

> 當我躺在床上、腦袋還停不下來，我想要一個安靜、會慢慢變暗、不會突然出聲的東西陪著，讓我不用一直盯著螢幕也能睡著。

- 他們現在雇用：YouTube、Spotify 上的雨聲、白噪音、ASMR 影片；睡眠 app。
- 證據：SBS 報導睡眠影片很紅，但廣告把人吵醒；r/asmr 有人說 YouTube 的廣告毀了他的睡眠；Spotify 社群一樣，雨聲 podcast 中間插廣告；有人說 app 一停播他就醒（r/raining）。
- 牠現在有：雨聲、柴火、夜晚背景，牠會睏、會睡。
- 缺口：
  - 聲音用的是 `.ambient`（`SlimeAudio.swift` 137 行）。Apple 文件寫明這個類別會被靜音開關和鎖定畫面靜音，等於要開著螢幕才有雨聲。
  - 沒有計時淡出。
  - 雨聲裡有雷（`amb.json`：每分鐘 0.12 次、間隔至少 300 秒、音量 0.4 到 0.7），大腦提案的「怕」又會被突然的大聲觸發。睡前最不想要的就是突然的聲音。

### 不會雇用牠的時刻 D｜手要一直忙的時候：開會、上課、想事情

- Fidget Cube 官方 app 的評論：實體方塊可以一邊做事、一手無意識地玩，app 太費事，做不到。
- 明治大學的堀田修吾說，數位世代反而追求摸得到的實物，實物的觸覺比螢幕模擬新鮮（聯合新聞網）。
- 結論：這個時刻實體捏捏樂贏。跟你 11-07「手癢不成立」一致，不要為它加功能。

### 三個時刻底下同一層：不被要求

三個時刻的人都在躲同一件事：廣告要你看、寵物要你照顧、通知要你回來、自我照顧 app 要你打卡。越要人出力的越快被丟：心理健康 app 裡，呼吸練習類的 30 天留存中位數是 0%（Baumel 等，2019）。所以「不被要求、不被打斷、不愧疚」這一層，比任何單一功能都重要。你的不做清單（飢餓值、懲罰、推播「牠想你了」、每日任務、心情打卡）剛好守在這裡，別讓之後的功能從後門把它帶回來。

## 四、四股力量（整個 app）

| 力量 | 內容 | 對設計的意思 |
|---|---|---|
| 推力 | 史萊姆 app 的廣告和訂閱；睡眠影片的廣告；寵物 app 的愧疚通知；實體史萊姆在家裡、學校被禁 | 全是「被打斷、被要求」，你要贏在「什麼都不要求」 |
| 拉力 | 摸得到、會認得你、不用照顧、沒廣告 | 上架頁和前十秒要看得到 |
| 焦慮 | 「又一個要照顧的東西？」「又是廣告和每週訂閱？」「要給動作權限？」 | 第一個畫面不問任何東西；權限照 lessons 11-06：先有不用權限就成立的動作 |
| 習慣 | 手已經會自動打開 IG；已經有固定那支雨聲影片 | 打開的路要比 IG 短：主畫面上就看得到牠（小工具） |

實體捏捏的甲醛、TVOC 新聞（台灣、香港媒體報過中國的檢測）也是推力，但你 11-07 已經不跟捏捏樂比，拿它寫文案會把定位拉回舊的那個。

### F1 第一下就抓得到

- 現況：開場途中碰到，牠 0.25 秒回家，這一下不抓（`SlimeRig.swift` 1962 行）。自己的生活提案又想把「從窗外回來」當成打開的獎勵。
- 做法：開場途中的第一下直接抓住；回家動畫照演，手指優先。獎勵不能擋路。
- 驗：06-首次體驗的秒表，「打開到第一次捏」。

### F2 好的結尾

- 做法：連續揉一段時間、「想被摸」退到底以後，牠不走開，而是軟下來、閉眼，在你最後摸的地方睡著。畫面變安靜，聲音淡掉。想繼續捏就捏（牠醒來，不生氣）；想走就放下手機。沒有任何字，不說「明天見」。
- 為什麼：書 2-9，人記得的是高峰和結尾。走開讀起來是被拒絕；睡著讀起來是牠滿足了。
- 跟大腦第 1 片「摸夠了會走開」（你 11-14 同意預設關）的差別：這是換一種結尾，不是把那個開關打開。
- 驗：可用性測試記三種反應：放下手機、繼續捏、說「牠不理我了」。

### F3 不嚇人的底線

- 做法：列一張「會讓人嚇一跳」的清單，逐條定上限：雷（睡前和陪睡不出現）、東西倒下的聲音峰值、`startle` 驚嚇聲、被猛扯的抗議聲。牠的怕用身體表現（縮、退、黏窗框），聲音小。
- 為什麼：活物感需要怕，但打開 app 的人正是想要不被嚇到的人。看牠害怕，有人會覺得是自己害的，跟愧疚是同一條線。
- 撞到：大腦五個需求裡「怕」的來源（突然的大聲：雷、東西倒下；搖手機），你 11-14 點頭的設計。要你決定。
- 驗：可用性測試記「皺眉、縮手、說『牠是不是怕我』」的次數。

### F4 陪睡

- 做法：一個看得見的入口（位置交給 wireframe），開了以後：
  - 鎖了螢幕雨聲還在，20、40、60 分鐘慢慢淡掉（數字我取的，待測）。
  - 雷和突然的事件關掉；牠睡著；畫面變暗。
- 技術：鎖螢幕還要有聲音，要換 `.playback` 類別並宣告背景音訊（`UIBackgroundModes` 的 audio，現在 `project.yml` 沒有）。`.playback` 不理會靜音開關，所以只在陪睡時切過去，平常維持 `.ambient`，公共場合才不會突然出聲。
- 審核（會過時，送審前查現行條文）：指南 2.5.4 允許背景服務用在音訊播放這類原本的用途；論壇上有開發者因為審核員找不到背景音訊功能，被退了好幾次，送審說明要寫清楚怎麼開。也有人把背景播放做成訂閱被退（論壇案例，4.10）。我的建議：陪睡不收錢，也不綁在付費窗景上。
- 驗：三天測試加一題：有沒有人睡前打開？打開後多久放下？

### F5 小工具：不打開也看得到牠

- 做法：主畫面和鎖定畫面的小工具，只畫牠現在的樣子：白天醒著、晚上睡著、今天帶回來的東西黏在身上、你選的窗景。點下去直接到牠面前。不放數值、不放「牠想你」、不放提醒。
- 為什麼：小工具寵物的評論說明「打開手機就看到牠」本身就有人要；你的版本是不要求任何東西的那種，市面上的都在要求。另一個理由在四股力量的「習慣」：打開的路要比 IG 短。
- 系統（會過時，做之前查）：iOS 27 的 iPhone 有超大尺寸小工具（MacStories 評測）；待機模式（StandBy，充電＋橫放）iOS 27.3 換新設計，Apple 說 12 月推出，第三方小工具在新的待機畫面怎麼放要查。小工具不能跑物理，只能畫圖，要 app 存一份「牠現在的狀態」給小工具讀。
- 撞到：總管約束 6，通知、收集這類放大器要等閘門 1。小工具不是推播，但它是叫人回來的系統觸點（書 2-12「小工具／捷徑」那一組）。❓ 我建議等閘門 1，但現在就先讓 app 把「牠現在的狀態」存成一份檔，之後做起來快。
- 驗：三天測試裡，第二天自己打開的人，是從圖示還是小工具進來的。

### F6 一段過去看得見

- 做法：長大提案（捏過的天數越多越大，畫面上沒有數字），加上「牠記得的事」從行為看得出來：常睡的位置、你常摸的地方、帶回來最久的那件東西擺在哪。
- 為什麼：Finch、貓咪後院的人幾週後離開，理由是新鮮感退了、收集完了。你不靠內容量，靠「牠跟別人的那隻不一樣，因為是你養的」。
- 順序：等熟跨天在真機上跑過。

### F7 上架頁與第一個畫面

- 這不是功能，是文字和第一個畫面：沒有廣告、不用照顧、不會傳通知催你。照核心動作卡的註記，不寫「紓壓」「療癒」。
- 為什麼：這個類別的評論都在罵廣告和訂閱。少掉類別的痛，本身就是拉力。
- 交給：`domi-aso-copy`（上架時）、`domi-uiux-onboard`（第一個畫面）。

## 九、怎麼驗：JTBD 訪談（把情境欄從想像換成真人）

**目的**：情境欄每條改成「訪談 n 人」；找出哪個時刻最常出現。

**找誰**：5 到 8 人，沒看過這個 app，最好不是好朋友（元邊界 7：認識你的人最客氣）。最近一個月做過下面任一件事：
- 看捏史萊姆、ASMR 影片放鬆
- 買過捏捏、NeeDoh
- 用過或刪過 Finch、貓咪後院、Widgetable、史萊姆 app
- 睡前放雨聲、白噪音

**問「最近一次」，不問「你會不會」**：
1. 最近一次是什麼時候？在哪？用哪隻手？躺、坐、站？手上還拿什麼？旁邊有人嗎？有開聲音嗎？（core 的情境觀察清單）
2. 前一刻發生什麼，讓你想做這件事？（推力）
3. 那時還想過什麼別的做法？為什麼選這個？（對手）
4. 做了多久？怎麼停下來的？停下來以後去做什麼？（結尾）
5. 有沒有哪次用到一半很煩、不想再用？那次發生什麼？（開除的理由）
6. 它明天消失的話，你會改用什麼？（真正的對手）
7. 有沒有本來想試、結果沒試的？卡在哪？（焦慮、習慣）

能的話，最後請他打開最近一次用的那個東西（影片、捏捏、貓咪後院），照平常那樣用一分鐘，你只看不講話。這一段是觀察，比他說的準。

**記錄表**

| 人 | 時刻（A／B／C／D／其他） | 最近一次的情境（手、姿勢、地點、聲音、多久） | 前一刻發生什麼 | 對手 | 怎麼停 | 開除的理由 | 原話 |
|---|---|---|---|---|---|---|---|
| 1 | | | | | | | |
| 2 | | | | | | | |
| 3 | | | | | | | |
| 4 | | | | | | | |
| 5 | | | | | | | |

**怎麼讀**：同一個時刻有 3 人以上，寫進核心動作卡的情境欄，標「訪談 n 人」；只有 1 人的，留在假設。

**跟閘門 1 的三個測試一起做**：先訪談（不給看 app），再做一句話測試（給看畫面）。反過來的話，看過畫面的人會照畫面回答。

**不要做**：
- 不要問「你會用這個功能嗎」（🔴 使用者說要的，不等於會用）
- 不要先說這是紓壓或寵物
- 不要讓他知道是你做的（書 3-7：以為是訪談者做的，偏好會多 2.5 倍）
